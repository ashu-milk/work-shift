# 💇‍♀️ シフトカレンダー作成アプリ

美容師さん向けの「定休日・公休日入力ができる、SNS投稿用のかわいいシフトカレンダー」を作るWebアプリです。
ビルド不要のシンプルなHTML / CSS / JavaScriptだけでできているので、GitHub Pagesにそのままアップロードしてすぐ公開・利用できます。

## オフラインでも使えます

フォント（Zen Maru Gothic / Caveat）とPNG書き出し用ライブラリ（html2canvas）はすべてこのフォルダの中に同梱されており、外部サーバーには一切通信しません。インターネットに繋がっていなくても、`index.html` をブラウザで開けばフォーム入力・テンプレート切り替え・PNGダウンロードまで全部動作します（実際に通信を完全遮断した状態でテスト済みです）。GitHub Pagesに公開した後も、一度ページを開いてブラウザにキャッシュされていれば、電波が入らない場所でも引き続き使えます。

## できること

- 年・月を選んでシフトカレンダーを作成
- 毎週の定休日（曜日）を複数選択できる
- 公休日（不定休）の日付をカンマ区切りで入力できる
- サロン名・スタイリスト名を入れられる
- 季節感のあるデザインテンプレートが8種類（ベーシック / 春・さくら / 夏・あじさい / 夏・花火 / 秋・紅葉 / 秋・モノトーン / 冬・雪 / 冬・クリスマス）
- SNS投稿しやすい正方形（1080×1080）のPNG画像としてダウンロード
- 入力内容はブラウザに自動保存され、次回開いたときに前回の内容を引き継ぐ
- 名前を付けて複数のプリセットとして保存・読み込みができる（店舗・スタイリストごとの使い分けなどに）

## 画面構成（フッタータブ）

スマホアプリのように、下部のタブで4つのページを切り替える構成になっています。

1. **基本情報** — 年月・サロン名・スタイリスト名・定休日（曜日）・公休日を入力
2. **テンプレート** — 季節のデザインを選ぶ（選ぶと下にプレビューが表示されます）
3. **SNS投稿用** — 出来上がったカレンダーを確認してPNGをダウンロード
4. **保存・読込** — 現在の内容をプリセットとして保存／呼び出し

なお、31日まである月で1日が金曜・土曜から始まる場合など、カレンダーが6週分になる月は自動的に少しコンパクトな表示に切り替わり、内容が枠からはみ出さないようになっています。

## フォルダ構成

```
shift-calendar-app/
├── index.html          # アプリ本体（この画面を開いて使う）
├── css/
│   └── style.css       # デザイン（レイアウト・テンプレート用のCSS変数）
├── js/
│   ├── templates.js    # 季節テンプレートの定義（色・モチーフなど）
│   ├── app.js          # アプリのロジック（入力・描画・保存・PNG出力）
│   └── vendor/
│       └── html2canvas.min.js  # 画面をPNG画像として書き出すためのライブラリ（同梱・オフライン動作用）
├── fonts/
│   ├── fonts.css        # フォントの読み込み設定
│   └── files/            # フォント本体（woff2、同梱・オフライン動作用）
├── icons/                # ブラウザタブ・ホーム画面アイコン各サイズ
├── favicon.ico
├── manifest.json         # スマホのホーム画面に追加したときの見た目設定
└── README.md
```

## 使い方（自分のPCで試す）

ブラウザで `index.html` を直接開くだけで動作します。ダブルクリックでも構いません。

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作成します（例: `shift-calendar-app`）。
2. このフォルダの中身一式（`index.html`, `css/`, `js/`, `README.md`）をリポジトリにアップロードします。
   - GitHubの画面から「Add file」→「Upload files」でドラッグ＆ドロップしてもOKです。
   - Gitを使える場合は以下のコマンドでもアップロードできます。

   ```bash
   cd shift-calendar-app
   git init
   git add .
   git commit -m "シフトカレンダーアプリを追加"
   git branch -M main
   git remote add origin https://github.com/【あなたのユーザー名】/shift-calendar-app.git
   git push -u origin main
   ```

3. GitHubのリポジトリ画面で「Settings」→ 左メニューの「Pages」を開きます。
4. 「Build and deployment」の「Source」を **Deploy from a branch** にし、Branchを **main** / フォルダを **/(root)** に設定して「Save」します。
5. 数分待つと、`https://【あなたのユーザー名】.github.io/shift-calendar-app/` でアプリが公開されます。
6. スマホ・PCどちらのブラウザからでもこのURLにアクセスすれば、いつでもカレンダーを作成できます。

## アイコンについて

ブラウザのタブに表示されるファビコンや、スマホのホーム画面に追加したときのアイコンとして、カレンダー×はさみモチーフのオリジナルアイコンを同梱しています(`icons/`フォルダ、`favicon.ico`)。スマホのブラウザで「ホーム画面に追加」をすると、このアイコンでアプリのように起動できます。差し替えたい場合は同じファイル名で好きな画像に置き換えてください。

## テンプレートを増やしたいとき

`js/templates.js` の `CALENDAR_TEMPLATES` 配列に、既存のテンプレートと同じ形式でオブジェクトを1つ追加するだけで、テンプレート選択に自動で反映されます（レイアウトを共通化しているので、色とモチーフ絵文字を指定するだけでOKです）。

## 注意事項

- 入力内容の保存にはブラウザの localStorage を使用しています。同じブラウザ・同じ端末でのみ内容が引き継がれます（別の端末やブラウザで開いた場合は引き継がれません）。
- PNGダウンロード機能は `html2canvas` というオープンソースライブラリを同梱して使用しています。
